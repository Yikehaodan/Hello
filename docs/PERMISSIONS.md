# macOS 权限与数据

## 首次启动

Hello 首次打开会显示权限说明。查看说明不会自动请求所有权限，只有点击对应按钮或主动开始录音后才会发起相关请求。可以先跳过，之后在“设置 → 权限”中继续。

| 权限 | 用途 | 拒绝后的影响 |
| --- | --- | --- |
| 麦克风 | 录制主动发起的口述 | 无法录音，仍可用文本工作台 |
| 辅助功能 | 全局 Fn、读取输入框或选文、写回结果 | 可用窗口按钮录音并手动复制 |
| 屏幕录制 | 上下文听写的可选窗口截图 | 不影响普通听写、翻译和提问 |

系统入口是“系统设置 → 隐私与安全性”。不同 macOS 版本可能将截图权限显示为“屏幕录制”或“屏幕与系统音频录制”。Hello 不录制系统音频。

新安装默认关闭“上下文听写附带窗口截图”。需要同时开启这个选项并获得系统授权，应用才会截图。单纯授权不会自动开启截图。

## 授权后没有生效

返回 Hello 后，权限状态会重新检查，也可以点击“重新检查”。如果状态未更新或快捷键仍不响应，先退出并重新打开应用。

请把应用放到固定位置后再授权。临时签名应用在重新编译、更新或移动后，系统可能要求重新授权。必要时在系统权限列表移除旧条目，再添加当前 `Hello.app`。不要为了使用 Hello 关闭系统整体安全保护。

如果麦克风显示“系统限制”，可能需要设备管理员处理。若 Fn 同时启动系统听写、表情面板或其他语音工具，请在系统键盘设置与对应工具中检查冲突。

## 数据去向

| 操作 | 数据与接收方 |
| --- | --- |
| 本地语音识别 | 录音由 Mac 上的模型处理 |
| 豆包云端识别 | 录音发送至配置的豆包语音服务 |
| 自动整理、翻译和问答 | 相关文字及词典内容发送至配置的文字服务；提问可能包含选中文字 |
| 上下文听写 | 输入框、窗口标题与可选截图发送至文字服务；OCR 在本机处理 |
| 天气查询 | 城市查询发送给 Open-Meteo 服务，不读取系统定位 |
| 额外配置的联网搜索 | 查询词发送给用户配置的搜索服务 |

选择本地模型并关闭自动整理后，普通听写可离线运行。翻译、问答与上下文听写仍需要文字服务。

历史记录、词典、保留录音和上下文截图存储在本机。保留期限可在“本机数据”设置中调整；删除记录会清理对应附件。选择“不保存”会清除已有历史和附件，请先确认需要保留的内容。API 配置以仅当前用户可读写的本地文件保存，不包含在仓库或构建产物中。

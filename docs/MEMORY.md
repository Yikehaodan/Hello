# 个人记忆

个人记忆用于减少重复纠正名字、术语和固定表达的次数。应用会把“小雪 → 晓雪”这样的纠正存入本机 `memory.md`，在后续识别和文字处理中参考。

## 开启与使用

在“词典 → 个人记忆”中开启功能。默认关闭，开启前会说明观察范围和数据发送方式。后台整理复用“设置 → 服务配置”中的服务地址、API Key 和模型，无需另外配置。

1. 在输入框中使用普通听写或上下文听写。
2. Hello 写入文字后，直接在原输入框中修改名字或固定表达。
3. Hello 最多观察 30 秒。切换输入框、切换应用或开始下一次录音时，结束观察。
4. 停止修改后，候选片段会在空闲时交给文字服务整理。也可以到个人记忆页点击“整理候选”。

自动捕获要求应用能读取原输入框、确认粘贴结果和定位插入范围。密码框、不可读的编辑器和无法确认写入结果的情况会跳过。用户撤销纠正后，不会把已撤销的修改记为习惯。

如果目标应用不支持自动捕获，可以点击“记住一个写法”，填写原写法、偏好写法和适用范围。

## 哪些内容会记住

名字和专有词的纠正首次记录为待确认建议。同一种纠正在至少两次独立听写中出现，且没有冲突时，短词纠正可以自动启用。同一段文字反复修改只算一次。启用后，应用窗口会显示可撤销的提示。

固定表达偏好需要用户确认后启用。例如把“好的”改回“OK”，只供普通听写参考。第一版不从整段改写推断用户整体的语气或写作风格。

数字、日期、金额变更、纯删除和未发生变化的文字不作为纠正候选。模型还会判断其他事实变化。模型建议必须引用真实修改记录，并能准确解释修改前后的差异，程序才会接受。模型自己的整理结果、记忆的使用次数和“用户没有修改”都不作为学习证据。

模型分类仍可能出错，尤其是无法区分“改错别字”和“换一个人”的情况。可以在记忆页查看、编辑、停用或删除。发生反向纠正时，原规则会暂停；删除并选择不再学习的纠正不会被自动加回。

## 下一次怎样使用

支持词典提示的识别引擎会参考已启用的正确词。文字整理时，应用最多附带 6 条与本次内容相关的记忆。表达偏好仅用于普通听写。

记忆是有适用范围的参考，不执行全文查找替换。当前明确说法、事实、否定、引文及翻译目标优先。例如人物称呼“晓雪”不应覆盖节气“小雪”。纯本地识别和不同文字模型的实际效果会有所不同。

## 保存与数据去向

文件位于应用数据目录下的 `memory.md`。新安装通常为 `~/Library/Application Support/Hello/memory.md`，从旧版升级时会沿用已有数据目录。页面提供“打开文件”和“重新读取”。

文件包括可读摘要和带固定字段的 JSON 记录。应用只解析 JSON 中的字段，不把 Markdown 自由文本作为系统指令。可通过应用编辑记忆；外部编辑文件后，先点击“重新读取”。无法解析的文件会保留原样，并停用记忆使用与写入。

捕获过程临时读取原输入框来定位插入范围，结束观察后释放正文。长期保存的是局部修改片段和记忆。候选片段最多保留 30 天，已确认的记忆保留至删除。记忆的保留设置独立于听写历史；清理历史不会删除已学习的记忆。

后台整理只向配置的文字服务发送本批候选片段及相关记忆，不发送截图或录音。每批最多 8 条，失败后保留候选，后续操作或手动重试时再处理。开始录音或文字处理会取消后台整理，不阻塞听写流程。

停用个人记忆后，自动捕获、后台整理和记忆引用都会停止，本机文件仍保留。“清空候选片段与未确认建议”可删除候选，已启用的记忆可以逐条删除。
